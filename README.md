# godi-ml

> ML quality assurance via LLM sub-agents. Catch what AutoML doesn't catch.

**Status:** Pre-alpha — under active development.

## What it does

`godi-ml` runs your binary classification dataset through a deterministic ML pipeline (5 models compared) and produces an evaluation report. Sub-agents catch data leakage, miscalibration, and subgroup bias automatically.

## Install (coming soon)

```bash
pip install godi-ml
```

## Quick start (coming soon)

```bash
godi-ml churn --data customers.csv --target churned
```
